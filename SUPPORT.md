# Getting support

- **Problems, questions and ideas:**
  [open an issue](https://github.com/galascribe/support/issues/new/choose) in this repository.
  Search [existing issues](https://github.com/galascribe/support/issues?q=is%3Aissue) first.
- **Account, billing or anything private:** email
  [support@galascribe.com](mailto:support@galascribe.com). Never post private details in an issue.
- **Security vulnerabilities:** see [SECURITY.md](SECURITY.md).
