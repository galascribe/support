# Galascribe Support

This is where you get help with [Galascribe](https://galascribe.com): report a problem, ask a
question, or suggest an idea. Everything here is public, so others with the same question can find
the answer too.

## Get help

1. **Search first.** Someone may already have asked:
   [search existing issues](https://github.com/galascribe/support/issues?q=is%3Aissue).
2. **Open an issue.** Choose what fits:
   [open an issue](https://github.com/galascribe/support/issues/new/choose).
   - **Something isn't working**: a bug in the App, your published site or an email from us.
   - **Question**: how to do something in Galascribe.
   - **Idea**: something you'd like Galascribe to do.
3. **We reply on the issue.** You'll get a GitHub notification when we do. Please answer any
   follow-up questions there, so the whole story stays in one place.

You need a free GitHub account to open an issue.

## Keep private things private

Issues are public. **Never post** passwords, access tokens, API keys, payment details, private
email addresses or anything else you wouldn't put on a public web page.

For anything about your account, billing, personal data or another private matter, email
[support@galascribe.com](mailto:support@galascribe.com) instead.

## Security

Found a security vulnerability? Please don't open an issue. Follow [SECURITY.md](SECURITY.md) to
report it privately.

## What makes a good report

- The address of the page or site where it happened
- What you did, what you expected, and what happened instead
- A screenshot, with any private details covered
- Your browser and device

## Community guidelines

Be kind and stay on topic. See our [Code of Conduct](CODE_OF_CONDUCT.md).
