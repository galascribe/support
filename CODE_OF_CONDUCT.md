# Code of Conduct

This repository is a place to get help with Galascribe. To keep it useful for everyone:

- **Be respectful.** No harassment, insults, discrimination or personal attacks.
- **Stay on topic.** Keep issues and comments about Galascribe.
- **Keep it public-safe.** Don't post anyone's private information, your own included.
- **No spam or promotion.**

We may edit or hide comments, lock or close issues, and block accounts that break these guidelines.
To report a problem with someone's behaviour, email
[support@galascribe.com](mailto:support@galascribe.com).
